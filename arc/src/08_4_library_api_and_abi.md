# Library API and ABI

## Public API (`include/dibeast/`)

| Header | Content |
|---|---|
| `DialApp.h` | Facade: `Config{device, httpPort = 56789, threads = 0}`, `makeProcessLauncher`, `addApp`, `setAppController`, `exec`, `stop` |
| `AppLauncher.h` | Abstract: `launch`, `stop`, `hide` (default: not implemented); `LaunchRequest`, `ExitCallback` |
| `AppController.h` | Abstract: `attach`, `info`, `launch`, `stop`, `hide`, `additionalData`, `onExit` |
| `AppEnvironment.h` | Abstract, implemented by the library: `descriptor`, `state`, `launcher`, `exitCallback` |
| `DefaultAppController.h` | The DIAL 2.2.1 behaviour, exported and subclassable |
| `Types.h` | `DeviceInfo`, `AppDescriptor`, `AppState`, `RunState`, `AppRequest`, `Reply`, `AdditionalData` |
| `Result.h` | See [Error Handling](08_2_error_handling.md) |
| `Export.h` | Generated by CMake: `DIBEAST_EXPORT` |

Naming: abstract classes are named for their role (no `I` prefix); built-in implementations use
the `Default` prefix.

## ABI rules

| Rule | How |
|---|---|
| Only marked symbols are API | Hidden visibility by default; public classes carry `DIBEAST_EXPORT` |
| One place decides the exported set | Linker version script: only `dibeast::` symbols, tagged `DIBEAST_0` |
| No Boost in the ABI | Public headers include no Boost; Boost is linked privately and its symbols hidden |
| Concrete public classes can grow | `DialApp` and `DefaultAppController` keep their data behind a pimpl |
| vtables live in the library | Abstract classes have out-of-line destructors |
| No exceptions across the boundary | Errors are `Result` values |
| Same toolchain | `std` types appear in the API, so client and library use the same compiler and standard library |

The exported set is checked with `nm` / `readelf`: only `dibeast::` names at `DIBEAST_0`, no
`boost::`, `SONAME libdibeast.so.0`.

## Versioning

`libdibeast.so.<major>.<minor>.<patch>` with `SONAME libdibeast.so.<major>` (currently 0.1.0).

| Change | Version |
|---|---|
| New class, new non-virtual function | minor |
| New or reordered virtual function, changed public struct layout or signature, removed symbol | **major** (new SONAME and version node) |
| Behaviour fix, no API change | patch |
